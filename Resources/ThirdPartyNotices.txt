The build scripts pin the libVLC revision, apply the upstream patches and list
the contributed libraries and their source downloads.

The framework is dynamically loaded. Its only binary modifications are selecting
the matching CPU slice and applying our distribution signature. You may replace
it with an API-compatible modified build. For local use, re-sign the replacement
framework first, then the app, with codesign --force --sign - on each bundle.
This does not require Tunerfenster source code or object files. Reverse
engineering for debugging modifications to the LGPL component is permitted.

dann App). Die LGPL-Rechte bleiben erhalten, einschließlich der Fehlersuche an
