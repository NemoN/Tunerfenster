## English

- Support for multiple TVHeadend servers.
- Install updates in the app, starting with version 2.1.
- Comskip commercial markers and optional automatic skipping.
- TV mode and recording playback improvements.

## Deutsch

- Unterstützung für mehrere TVHeadend-Server.
- Updates ab Version 2.1 in der App installieren.
- Comskip-Werbemarkierungen und optionales automatisches Überspringen.
- Verbesserungen im TV-Modus und bei der Wiedergabe von Aufnahmen.
