# Tunerfenster 1.8.0

## English

Tunerfenster now checks GitHub for updates and offers the correct installer
for your Mac.

- Automatic checks once a day, with a small notice that leaves TV playback running.
- **Tunerfenster → Check for Updates…** for a manual check at any time.
- Automatic checks can be disabled in Settings or the Software Updates window.
- Apple Silicon or Intel DMG selected from the hardware, including Apple Silicon
  when running the Intel app through Rosetta.
- Only newer stable releases are offered. Missing CPU-specific downloads are
  explained; known updates survive a restart or a failed network request.
- All update messages are available in English and German.

Download the DMG, quit Tunerfenster and drag the app into Applications to replace
the installed version. Existing settings are preserved. Version 1.8.0 introduces
the check; install it once to receive notices for future releases.

**macOS 14 or later.** VLC is included. Both DMGs and apps are Developer ID
signed, Apple-notarized and supplied with stapled tickets. The update check
uses the public GitHub API without TVHeadend credentials. Installation remains
manual.

Validation: 55 tests including the public GitHub release API; native Apple
Silicon and Intel under Rosetta; H.264/AAC playback from both signed apps and
fresh copies from the DMGs; signature, notarization ticket and Gatekeeper checks.

## Deutsch

Tunerfenster prüft jetzt GitHub auf Updates und bietet die passende
Installationsdatei für deinen Mac an.

- Automatische Prüfung einmal täglich. Ein Hinweis lässt die TV-Wiedergabe weiterlaufen.
- **Tunerfenster → Nach Updates suchen …** für eine manuelle Prüfung jederzeit.
- Automatische Prüfungen sind in den Einstellungen oder unter Softwareupdates abschaltbar.
- Passende DMG für Apple Silicon oder Intel anhand der Hardware, auch Apple Silicon
  bei einer unter Rosetta gestarteten Intel-App.
- Nur neuere stabile Versionen werden angeboten. Fehlende CPU-Downloads werden
  erklärt; gefundene Updates bleiben nach Neustart oder Netzwerkfehler erhalten.
- Alle Update-Meldungen auf Deutsch und Englisch.

Lade die DMG, beende Tunerfenster und ziehe die App in Programme, um die
installierte Version zu ersetzen. Vorhandene Einstellungen bleiben erhalten.
Version 1.8.0 führt die Prüfung ein; installiere sie einmal, um Hinweise auf
künftige Releases zu erhalten.

**Ab macOS 14.** VLC ist integriert. Beide DMGs und Apps sind mit Developer ID
signiert, von Apple notarisiert und mit angehefteten Tickets versehen. Die
Update-Prüfung nutzt die öffentliche GitHub-API ohne TVHeadend-Zugangsdaten.
Die Installation erfolgt manuell.

Geprüft: 55 Tests einschließlich der öffentlichen GitHub-Release-API; Apple
Silicon nativ und Intel unter Rosetta; H.264/AAC-Wiedergabe aus beiden signierten
Apps und frisch aus den DMGs kopierten Apps; Signaturen, Notarisierungstickets
und Gatekeeper.
